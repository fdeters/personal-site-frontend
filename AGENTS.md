# Project instructions

- Use Node.js 26 and pnpm 12.18.0. Install dependencies with
  `pnpm install --frozen-lockfile`; do not introduce another package manager or
  lockfile.
- Keep changes consistent with the existing SvelteKit, Tailwind CSS, and
  Prettier setup. Update this file and `README.md` when development commands or
  project conventions change.
- Run `pnpm check`, `pnpm test`, `pnpm format:check`, and `pnpm build` for
  changes that affect application code or dependencies.
